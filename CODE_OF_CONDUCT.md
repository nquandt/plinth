# Code of conduct

Plinth uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in the repository, the issue tracker, pull requests and every other project space.

In short:

- Be respectful and kind. Disagree about ideas, not about people.
- Do not harass, insult or threaten anyone, and do not publish private information about anyone.
- Welcome newcomers and help them.

## Report a problem

Report behavior that breaks this code to the maintainers in private, through the contact on the repository's GitHub profile. Do not report it in a public issue. The maintainers read every report, keep the name of the reporter private, and act as the Contributor Covenant's enforcement guidelines describe.
