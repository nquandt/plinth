# The shared formatting cases of `plinth:locale` (core 1.13, docs/I18N.md
# §3.7, §4 step 2). The desktop test (`tests/locale_format.rs`, ICU4X,
# wasmtime and wasmi) and the web test (`web/test/run-locale.mjs`, the
# browser `Intl` of Node, the real core) build ONE app with a `Text` for each
# case, start it in each locale, and compare each text with this file. The
# time zone is UTC on both hosts.
#
# Format: `=== case <name>`, then one line with the expression (a `string`
# in Plinth TS; `plinth:locale` is imported), then one line for each locale:
# `<locale> <text>` (a locale alone: the empty string). In the text,
# `\u{hex}` is a code point and `\\` is a backslash; the tests write
# spaces other than U+0020 and the invisible marks in this form.
#
# A known difference between the hosts: `<locale>@desktop <text>` and
# `<locale>@web <text>`, then `known <locale>: <reason>`. A test fails when
# a host gives another text, and when a case has a host line without its
# `known` line. docs/I18N.md §3.7 lists the known differences.
#
# Timestamp 1791459845000 is 2026-10-08 11:44:05 UTC (a Thursday).
