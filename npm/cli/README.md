# @plinth/cli

The `plinth` command: build cross-platform apps from a strict subset of TypeScript with JSX. Apps compile to small WebAssembly components and run in the Plinth host with a native, adaptive UI.

```sh
npm create plinth@latest my-app
cd my-app
npm install
npm run dev
```

Commands: `plinth new`, `plinth dev`, `plinth check`, `plinth build`, `plinth run`.
